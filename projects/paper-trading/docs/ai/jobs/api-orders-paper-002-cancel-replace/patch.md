## 2. Implementation Summary

- Implemented adapter-level KIS paper cancel/replace only.
- Endpoint used: POST `/uapi/overseas-stock/v1/trading/order-rvsecncl`.
- TR_ID used: `VTTT1004U` only.
- Cancel body fields are exactly `CANO`, `ACNT_PRDT_CD`, `OVRS_EXCG_CD`, `PDNO`, `ORGN_ODNO`, `RVSE_CNCL_DVSN_CD`, `ORD_QTY`, `OVRS_ORD_UNPR`; cancel uses `RVSE_CNCL_DVSN_CD="02"` and `OVRS_ORD_UNPR="0"`.
- Replace body fields are the same exact set; replace uses `RVSE_CNCL_DVSN_CD="01"`, new `ORD_QTY`, and new `OVRS_ORD_UNPR`.
- Response parsing uses `rt_cd`, `msg_cd`, `msg1`, and `output.ODNO`; missing `rt_cd` or missing replacement `output.ODNO` fails closed as `malformed_response`.
- `KisOrderResponse` gained default fields `exchange`, `replacement_broker_order_id`, and `replaces_broker_order_id`.
- `KisBroker` now maintains internal `_order_history` for cancel/replace lookup.
- `place_order` records successful `ODNO` responses into `_order_history` and passes the validated order path to the transport.
- `cancel_order` updates the existing history entry to `status="cancelled"` and returns `None`.
- `replace_order` keeps the old key with `status="replaced"` and `replacement_broker_order_id`, creates a new key with `status="replacement_submitted"` and `replaces_broker_order_id`, updates `_last_order_response` to the new entry, and returns `OrderAck(status="replacement_submitted")`.
- Dry-run cancel sets `_last_order_preview`, skips transport, and returns `None`.
- Dry-run replace sets `_last_order_preview`, skips transport, and returns `OrderAck(status="dry_run", broker_order_id=None)`.
- Transport allowlists now cover paper host, path/TR_ID match, paper place TR_IDs, the single paper cancel/replace TR_ID, US exchanges only, LIMIT-only place orders, and cancel/replace `RVSE_CNCL_DVSN_CD` values.

G1-G4 decisions:

- G1: Selection A. `KisOrderResponse` has `exchange: str = "NASD"` plus replacement chain fields with defaults, preserving existing callers.
- G2: Selection A. Adapter-level only; no OMS/runtime/GUI/API wiring was added. `capabilities()["cancel"]` and `["replace"]` remain `False`.
- G3: Old replacement source IDs are preserved and linked to new IDs; new replacement IDs are stored separately and linked back to the source.
- G4: `KIS_PAPER_CANCEL_REPLACE_TR_IDS == frozenset({"VTTT1004U"})`; US exchange allowlist remains `NASD`/`NYSE`/`AMEX`.
