# 작업 입력 (Job Input) — 예시

> 이 파일은 `scripts/create-job.sh`가 만드는 템플릿이 어떻게 채워지면 좋은지 보여주는 **예시**입니다.
> 실제 작업에서는 `docs/ai/jobs/{JOB_ID}/input.ko.md` 안의 비어 있는 템플릿을 직접 채워주세요.

## 한 줄 요약
프로젝트 README.md 최상단에 한 줄짜리 한국어 + 영어 소개 문장을 추가하고 싶습니다.

## 배경 (Why)
- 지금 README가 거의 비어 있어서 처음 방문하는 사람이 이 프로젝트가 뭐 하는 건지 알기 어렵습니다.
- GitHub 검색으로 들어온 사람이 5초 안에 "내가 찾던 게 맞나?"를 판단할 수 있어야 합니다.
- 한국어 사용자와 영어 사용자가 둘 다 있어서 두 줄을 함께 두고 싶습니다.

## 목표 (Done 정의)
- [ ] `README.md`의 제목(`# ...`) 바로 아래에 한 줄 한국어 소개가 추가되어 있다.
- [ ] 그 다음 줄에 한 줄 영어 소개가 추가되어 있다.
- [ ] 기존 README 본문 내용은 그대로 보존된다.

## 범위 밖 (Not in scope)
- 로고, 배지, 스크린샷 추가는 이번 작업에서 다루지 않습니다 (다음 작업으로 분리).
- 영어 README를 별도 파일(`README.en.md`)로 분리하는 작업도 다음 기회에.
- 다른 마크다운 문서는 건드리지 않습니다.

## 제약 조건
- 코드 파일은 절대 건드리지 않습니다 — `README.md`만 수정.
- `.env`, 비밀 키, 자격 증명 변경 금지.
- 인증 / 결제 / DB 마이그레이션 / 운영 인프라 변경 금지.
- `main` 브랜치 직접 푸시 금지. 별도 브랜치로 PR.
- 자동 머지 금지.

## 참고 자료
- 비슷한 프로젝트들의 README 첫 줄 예시:
  - "A fast, type-safe HTTP client for Node.js."
  - "Manage your local AI dev team in tmux."
- 회사 문서 톤 가이드: (해당 없음)

## 수용 기준 (Acceptance Criteria)
- [ ] `head -3 README.md` 결과에 한 줄 한국어 소개가 보인다.
- [ ] 그 다음 줄에 한 줄 영어 소개가 보인다.
- [ ] `git diff`가 `README.md` 한 파일에만 국한되어 있다.
- [ ] 기존 README의 어떤 줄도 삭제되지 않는다 (추가만 한다).
