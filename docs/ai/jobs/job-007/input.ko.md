# 작업 요청

AI 개발팀 GUI 컨트롤센터의 최종 점검과 사용성 개선 계획을 작성한다.

## 목표

현재 만들어진 웹 GUI 컨트롤센터가 실제로 사용할 수 있는 상태인지 점검한다.
이번 job-007에서는 위험한 인프라 변경, 인증/비밀번호 구현, CI/CD 변경, 자동 merge는 하지 않는다.

이번 작업의 목적은 다음이다.

1. 현재 GUI 기능이 실제로 동작하는지 점검한다.
2. 사용자가 브라우저에서 대부분의 작업을 처리할 수 있는지 확인한다.
3. 아직 부족한 부분을 안전한 범위 안에서 정리한다.
4. 다음 작업 후보를 분리해서 문서화한다.

## 점검할 현재 기능

다음 기능이 실제로 동작하는지 확인한다.

- 전체 파이프라인 실행 버튼
- 실시간 파이프라인 상태 표시
- tmux 출력 보기
- 승인 / 세션 승인 / 거절 / 중단 버튼
- AI팀 재시작 버튼
- GUI 서버 재시작 버튼
- 산출물 목록 보기
- git status 보기
- git diff 보기
- Reviewer 결과 표시
- 최종 PR/merge는 사람이 직접 수행하도록 안내

## 개선하고 싶은 GUI 사용성

가능한 경우 안전한 범위 안에서 다음 사용성 개선을 제안한다.

- 불필요하거나 중복된 버튼 정리
- 주요 버튼과 고급 버튼 구분
- 현재 단계와 현재 대상 AI 창을 더 명확히 표시
- 승인 대기 상태를 더 잘 보이게 표시
- Reviewer 완료 후 다음에 무엇을 해야 하는지 안내
- GUI에서 사용자가 해야 할 최종 수동 작업을 체크리스트로 표시

## 이번 작업에서 금지

이번 job-007에서는 다음을 구현하거나 실행하지 않는다.

- git push 자동화
- PR merge 자동화
- 배포 자동화
- systemd 서비스 등록
- 서버 재부팅 자동 시작 설정
- GitHub Actions / CI 파일 수정
- 로그인, 비밀번호, 세션, 토큰 처리 코드 구현
- .env, token, secret, API key 읽기 또는 출력
- auth, payment, DB migration, production infra 수정
- 임의 shell command 실행 기능 추가

## 사람이 직접 해야 하는 항목

다음 항목은 이번 job에서 자동화하지 말고, 사람이 직접 승인하고 수행해야 하는 future work로만 정리한다.

- 최신 GUI 변경사항 commit / PR / merge
- 서버 재부팅 후 자동 실행 설정
- GUI 보안 강화
- CI 판정기 추가
- 프로젝트 여러 개 선택 기능 고도화
