# 안전 규칙 (Safety Rules)

AI 팀이 절대 어겨서는 안 되는 규칙입니다. 같은 규칙이 모든 역할 프롬프트(`prompts/*.md`)에도 들어 있습니다.

이 규칙은 **AI에 대한 규칙이자, 사람에 대한 규칙**입니다. 사람이 "그냥 빨리 하자"라고 우회하면 의미가 사라집니다.

## 1. 비밀 정보는 저장소에 두지 않습니다

- `.env`, API 키, 토큰, 자격 증명, 비밀번호를 커밋하지 않습니다.
- 누가 그런 파일을 만들거나 수정하라고 하면 AI는 **즉시 멈추고 사람에게 보고**합니다.
- 이미 커밋된 비밀이 있으면 `git filter-repo` 등으로 히스토리 정리가 필요합니다 — AI가 단독으로 처리하지 않습니다.
- `.gitignore`에 `.env`, `*.pem`, `*.key`, `.secrets/` 같은 패턴이 들어 있는지 작업 시작 전에 확인합니다.

## 2. `main` 브랜치 직접 푸시 금지

- 모든 변경은 별도 브랜치 → PR → 리뷰 → 머지 순서로 진행합니다.
- `git push origin main`은 사람이 의식적으로 결정한 경우에만, 그것도 매우 드물게 (예: 핫픽스 후 브랜치 정리).
- 강제 푸시(`--force`, `--force-with-lease`)는 사람이 명시적으로 지시한 경우에만 사용합니다.
- AI는 어떤 경우에도 `main`에 직접 푸시하지 않습니다.

## 3. 자동 머지 금지

- AI는 PR을 만들 수는 있지만 **머지하지 않습니다**.
- 머지는 사람이 리뷰 결과를 읽고 직접 누르는 행위입니다.
- `gh pr merge --auto`처럼 자동 머지 옵션도 사용하지 않습니다.
- Mergify, Bulldozer 등 자동 머지 봇 설정 변경도 사람 승인 영역입니다.

## 4. 운영 인프라 변경에는 사람 승인이 필요합니다

다음 영역은 사람의 **명시적 승인이 PR 본문이나 작업 폴더(`docs/ai/jobs/{JOB_ID}/`)에 기록된 경우**에만 손댑니다.

- Terraform / Pulumi / CloudFormation의 prod workspace
- 쿠버네티스 prod 매니페스트 / Helm chart values for prod
- CI/CD 파이프라인의 prod 배포 스텝 (GitHub Actions, GitLab CI, ArgoCD 등)
- DNS, 도메인 설정, TLS 인증서 발급/갱신
- Cloud IAM, 권한, 서비스 계정

## 5. 결제 / 인증 / DB 마이그레이션 변경에는 사람 승인이 필요합니다

다음은 한 줄만 바꿔도 사고로 이어질 수 있는 영역입니다.

- 인증 / 로그인 / 세션 / 비밀번호 / 토큰 처리 코드
- 결제 / 빌링 / 구독 / 환불 로직
- 데이터베이스 마이그레이션 파일 (스키마 변경, 데이터 백필, 인덱스 변경)

위 영역을 수정해야 하면:

1. 작업 폴더(`docs/ai/jobs/{JOB_ID}/`)에 "사람이 명시적으로 승인했다"는 메모를 남깁니다.
2. PR 본문에도 같은 내용을 적고, 어떤 사람이 언제 승인했는지 기록합니다.
3. Claude Reviewer는 이 메모가 없으면 `BLOCK` 판정을 냅니다.
4. 사람이 머지하기 전에 한 번 더 직접 코드를 봅니다.

## 6. 의심스러우면 멈춥니다

- 위 규칙 중 하나라도 애매한 상황이면 AI는 자체 판단으로 진행하지 않고 사람에게 묻습니다.
- "이 정도는 괜찮겠지"가 사고의 시작입니다.
- 규칙을 우회하고 싶은 합리적 이유가 보이면, 그 이유를 작업 폴더에 적고 사람이 승인할 때까지 대기합니다.

## 7. 사람만 할 수 있는 행동 (요약)

| 행동 | AI | 사람 |
|------|----|------|
| 한국어 요청서 작성 | ✗ | ✓ |
| 영어 계획 / 아키텍처 / 구현 / 리뷰 | ✓ | ✓ |
| `git commit` | ✗ | ✓ |
| `git push` | ✗ | ✓ |
| PR 생성 | △ (사람이 검토 후) | ✓ |
| PR 머지 | ✗ | ✓ |
| `.env` / 비밀 추가 / 수정 | ✗ | ✓ (드물게, 의식적으로) |
| 인증 / 결제 / DB 마이그레이션 변경 | △ (승인 메모 필수) | ✓ |
| 운영 인프라 변경 | △ (승인 메모 필수) | ✓ |
